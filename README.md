# Hospital Patient Management System

A Windows-based Hospital Patient Management System developed using
**C#**, **.NET Windows Forms**, and **SQL Server**. The application
helps hospital staff manage patient records efficiently through a simple
graphical user interface. The project supports creating, updating,
deleting, viewing, and navigating patient records stored in a SQL Server
database.

## Features

-   Add new patient records
-   Update existing patient information
-   Delete patient records
-   View all patient records
-   Auto-generated Patient ID
-   Automatic age calculation from Date of Birth
-   Data validation for required fields
-   Patient record navigation (First, Previous, Next, Last)
-   User-friendly Windows Forms interface

## Technologies Used

-   C#
-   .NET Windows Forms
-   SQL Server
-   ADO.NET
